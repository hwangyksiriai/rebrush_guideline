## 더 올리면 좋은 컷

| 파일 | 위치 | 쓰이는 곳 | 권장 |
| --- | --- | --- | --- |
| `banner.jpg` | 저장소 **루트** | 신청폼 4개 페이지 히어로 | **세로로 살짝 긴 비율(16:14 정도)**. 가로 3:2 컷을 넣으면 양옆이 크게 잘리고, 위쪽 60%에 제목이 얹혀 피사체를 가립니다. 아래쪽에 여백이 있는 컷이 좋습니다 |
| `banner.png` | `image/` | `guide.html` 배너 전용 | 가로형. 넣으면 `guide.html` 의 `<img src="image/product.png">` 를 `banner.png` 로 바꿔주세요 |

파일이 없으면 해당 영역은 자동으로 옅은 배경으로 대체되며 페이지는 정상 동작합니다.
