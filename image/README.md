# 가이드라인 페이지 이미지

`guide.html` 이 이 폴더의 파일을 참조합니다. 아래 이름 그대로 올려주세요.

| 파일명 | 쓰이는 곳 | 권장 |
| --- | --- | --- |
| `banner.png` | 가이드라인 최상단 배너 | 가로형. 위쪽 30~45%에 흰 스크림이 깔리고 그 위에 제목이 올라가므로, **피사체는 아래쪽·가운데**에 오는 컷이 좋습니다 |
| `product.png` | 캠페인 개요 > 제공 제품 | 가로형 제품 컷. 원본 비율 그대로 폭 100%로 표시됩니다 |

같은 사진을 두 곳에 써도 됩니다. 파일이 없으면 배너는 옅은 하늘색 배경으로,
제품 사진은 아예 숨겨진 채로 페이지가 정상 동작합니다.

`.jpg` 로 올리실 경우 `guide.html` 의 `<img src="image/banner.png">` 확장자도 함께 바꿔주세요.
