## leoj.png 권장

- **세로형**이 좋습니다. 카드 왼쪽에 폭 104px(좁은 화면 88px)로 들어가고 원본 비율이 유지됩니다.
- 인물이 화면에 크게 잡힌 컷일수록 작은 크기에서 알아보기 쉽습니다.
- 파일이 없으면 사진 자리만 빠지고 카드의 문구는 그대로 나옵니다.
