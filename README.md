# 리브러쉬 과즙 구강스프레이 · 캠페인 가이드

Re:Brush(리브러쉬) 과즙 구강스프레이 3종 인플루언서 캠페인 모집·가이드 페이지입니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 캠페인 신청 가이드 페이지 (단일 페이지) |
| `apps-script.gs` | 신청폼 → 구글 시트 저장용 Apps Script |

## 페이지 섹션

1. **캠페인 개요** — 고료 · 형식 · 공동작업자 · 업로드 일정 · 제공 제품
2. **제품 소개** — 브랜드 소개 및 제품 핵심 특징 4가지
3. **3종 컨셉** — 머루포도(PURE) · 청사과(COOLING) · 납작복숭아(CLEAN)
4. **제작 가이드** — 3가지 소구 방향 중 1개 이상 선택 (기능성 / 사용 상황 / 맛·향·사용감)
5. **광고 표현 가이드라인** — 의약외품 광고 금지 표현 및 핵심 3원칙
6. **주의사항**
7. **캠페인 신청하기** — 신청폼
8. **정산 안내**

## 확정 후 채워야 하는 항목

아래 값은 캠페인 조건이 확정되면 `index.html`에서 교체해 주세요.

- 상단 마감 바 · 캠페인 개요의 **업로드 일정**
- 캠페인 개요의 **고료** (현재 `개별 안내`)
- **공동작업자 인스타그램 계정**
- **필수 해시태그** (`#tagbox` 영역)
- 히어로 이미지 `banner.jpg`, 제품 이미지 `product.png`

## 이미지

`banner.jpg`(히어로)와 `product.png`(제품 썸네일)를 루트에 올리면 자동으로 표시됩니다.
파일이 없으면 해당 영역은 자동으로 숨겨지거나 '메인 사진 준비중'으로 표시됩니다.

## 로컬 미리보기

```bash
python -m http.server 5173
```

## 신청폼 연동

`index.html`의 `<form id="applyForm" ... action="...">` URL이 Apps Script 웹 앱 주소입니다.
현재는 기존 SIRIAI 캠페인과 동일한 엔드포인트를 사용하며, `campaign` 값(`리브러쉬 과즙 구강스프레이`)으로 시트에서 구분됩니다.
별도 시트로 분리하려면 `apps-script.gs`를 새 시트에 배포한 뒤 `action` URL을 교체해 주세요.
