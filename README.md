# 리브러쉬 과즙 구강스프레이 · 캠페인 페이지

Re:Brush(리브러쉬) 과즙 구강스프레이 인플루언서 캠페인 페이지입니다.
**가이드라인과 신청폼이 한 페이지에** 들어 있고, 고료별로 네 벌이 있습니다.

## 구성

| 경로 | 설명 |
| --- | --- |
| `index.html` | 허브 — 캠페인 유형(고료) 선택 |
| `a-type/index.html` | A Type · 50,000원 |
| `b-type/index.html` | B Type · 100,000원 |
| `c-type/index.html` | C Type · 200,000원 |
| `d-type/index.html` | D Type · 500,000원 |
| `apps-script.gs` | 신청폼 → 구글 시트 저장용 Apps Script |
| `vercel.json` | `cleanUrls` — `/a-type` 처럼 확장자 없이 열림 |

각 타입 페이지 구성: **배너 → 브랜드 소개 → 캠페인 개요(고료·일정·제공 제품·3종 선택)
→ 제작 가이드 → 광고 표현 가이드라인 → 캠페인 신청하기 → 정산 안내**

> 네 파일은 **고료와 티어 표기만 다르고 나머지는 완전히 동일**합니다.
> 내용을 고칠 때는 네 파일에 같은 수정을 적용해야 합니다.

## 캠페인 조건

- **업로드 기간** — 10월 1일 ~ 10월 7일 (기간 내 1회)
- **제공 제품** — 과즙 구강스프레이 1개 (머루포도 · 청사과 · 납작복숭아 중 택 1)
- **형식** — 릴스 1건 · 공동작업자 `@rebrush_official` 필수 · 2차 활용 동의 · 업로드 유지 3개월
- **해시태그** — `#리브러쉬` `#ReBrush` `#과즙구강스프레이` `#구강스프레이`

## 3종 택 1 — 선택 한 번으로 두 곳에 반영

캠페인 개요의 3종 선택 버튼을 누르면

1. 해당 향의 **핵심 역할 · 카피 · 권장 상황 · 맛 표현**이 바로 아래에 펼쳐지고
2. 페이지 하단 **신청폼의 `제품 선택` 칸에도 자동으로 채워집니다** (`flavor` 필드)

선택값은 `localStorage` 에도 남아 새로고침해도 유지됩니다.
미선택 상태로 제출하면 경고가 뜨고 선택 위치로 스크롤됩니다.

## 이미지

| 파일 | 쓰이는 곳 | 상태 |
| --- | --- | --- |
| `image/product.png` | 허브·타입 페이지 배너, 캠페인 개요 제품 사진 | ✅ 적용됨 (577×385, 3:2) |

배너는 사진이 원본 비율로 깔리고 위쪽에 흰 스크림 + 제목이 얹힙니다.
제목이 위쪽 35~40%를 덮으므로 피사체가 아래·가운데 있는 컷이 좋습니다.
파일이 없으면 옅은 하늘색 배경으로 대체되며 페이지는 정상 동작합니다.

## 신청폼 연동

각 페이지의 `<form id="applyForm" ... action="...">` URL이 Apps Script 웹 앱 주소입니다.
현재는 기존 SIRIAI 캠페인과 동일한 엔드포인트를 사용하며 `campaign` 값(`리브러쉬 과즙 구강스프레이`)으로
시트에서 구분됩니다.

> ⚠️ **`제품 선택`(향) 컬럼은 스크립트를 다시 배포해야 저장됩니다.**
> 현재 배포된 스크립트는 12개 컬럼까지만 기록하므로, `apps-script.gs` 를 시트에 반영하고
> 재배포하기 전까지 `flavor` 값은 저장되지 않습니다.
