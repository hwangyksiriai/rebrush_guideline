# 리브러쉬 과즙 구강스프레이 · 캠페인 가이드

Re:Brush(리브러쉬) 과즙 구강스프레이 3종 인플루언서 캠페인 모집·가이드 페이지입니다.

## 구성

| 경로 | 설명 |
| --- | --- |
| `index.html` | 허브 — 캠페인 유형 선택 |
| `a-type/index.html` | A Type · 50,000원 |
| `b-type/index.html` | B Type · 100,000원 |
| `c-type/index.html` | C Type · 200,000원 |
| `d-type/index.html` | D Type · 500,000원 |
| `apps-script.gs` | 신청폼 → 구글 시트 저장용 Apps Script |

네 타입은 **고료만 다르고 콘텐츠 조건과 가이드 내용은 동일**합니다.
신청폼에는 `tier`(A~D Type)와 `fee`(고료) 값이 함께 전송되어 시트에서 구분됩니다.

## 가이드 페이지 섹션

1. **캠페인 개요** — 고료 · 형식 · 공동작업자 · 업로드 일정 · 제공 제품
2. **제품 소개** — 브랜드 소개 및 제품 핵심 특징 4가지
3. **3종 컨셉** — 머루포도(PURE) · 청사과(COOLING) · 납작복숭아(CLEAN)
4. **제작 가이드** — 3가지 소구 방향 중 1개 이상 선택 (기능성 / 사용 상황 / 맛·향·사용감)
5. **광고 표현 가이드라인** — 의약외품 광고 금지 표현 및 핵심 3원칙
6. **주의사항**
7. **캠페인 신청하기** — 신청폼
8. **정산 안내**

## 확정 후 채워야 하는 항목

아래 값은 캠페인 조건이 확정되면 `*-type/index.html` 네 파일에서 함께 교체해 주세요.

- 상단 마감 바 · 캠페인 개요의 **업로드 일정**
- **공동작업자 인스타그램 계정**
- **필수 해시태그** (`#tagbox` 영역)

## 이미지

`banner.jpg`(히어로)와 `product.png`(제품 썸네일)를 **저장소 루트**에 올리면 네 타입 페이지에
모두 반영됩니다. 파일이 없으면 해당 영역은 자동으로 숨겨지거나 '메인 사진 준비중'으로 표시됩니다.

## 로컬 미리보기

```bash
python -m http.server 5173
```

## 신청폼 연동

각 페이지의 `<form id="applyForm" ... action="...">` URL이 Apps Script 웹 앱 주소입니다.
현재는 기존 SIRIAI 캠페인과 동일한 엔드포인트를 사용하며, `campaign` 값(`리브러쉬 과즙 구강스프레이`)으로
시트에서 구분됩니다. 별도 시트로 분리하려면 `apps-script.gs`를 새 시트에 배포한 뒤
네 페이지의 `action` URL을 교체해 주세요.
