# 리브러쉬 과즙 구강스프레이 · 캠페인 가이드

Re:Brush(리브러쉬) 과즙 구강스프레이 인플루언서 캠페인 페이지입니다.
**모집(신청폼)** 과 **선정자용 가이드라인** 두 갈래로 구성돼 있습니다.

## 구성

| 경로 | 설명 |
| --- | --- |
| `index.html` | 모집 허브 — 캠페인 유형 선택 |
| `a-type/index.html` | A Type · 50,000원 (신청폼 포함) |
| `b-type/index.html` | B Type · 100,000원 |
| `c-type/index.html` | C Type · 200,000원 |
| `d-type/index.html` | D Type · 500,000원 |
| `guide.html` | **선정자용 전체 가이드라인** (Vercel 배포 시 `/guide`) |
| `apps-script.gs` | 신청폼 → 구글 시트 저장용 Apps Script |
| `vercel.json` | `cleanUrls` — `/guide` 로 접근 가능하게 함 |

네 타입은 **고료만 다르고 콘텐츠 조건과 가이드 내용은 동일**합니다.

## 캠페인 조건

- **업로드 기간** — 10월 1일 ~ 10월 7일 (기간 내 1회)
- **제공 제품** — 과즙 구강스프레이 1개 (머루포도 · 청사과 · 납작복숭아 중 택 1)
- **형식** — 릴스 1건 · 공동작업자 필수 · 2차 활용 동의 · 업로드 유지 3개월

## 이미지 올리는 곳

**아직 아무 이미지도 올라가 있지 않습니다.** 아래 이름 그대로 올리면 자동으로 표시됩니다.

| 파일 | 위치 | 쓰이는 곳 |
| --- | --- | --- |
| `banner.png` | `image/` | 가이드라인 최상단 배너 |
| `product.png` | `image/` | 가이드라인 > 제공 제품 |
| `banner.jpg` | 저장소 루트 | 신청폼 4개 페이지 히어로 |
| `product.png` | 저장소 루트 | 신청폼 4개 페이지 제품 소개 |

같은 사진을 네 곳에 모두 써도 됩니다. 파일이 없으면 해당 영역은 자동으로
숨겨지거나 대체 배경으로 표시되므로, 지금 상태로도 페이지는 정상 동작합니다.

**컷 선택 요령**

- **배너 / 히어로** — 위쪽에 제목이 얹히므로 피사체가 아래·가운데 있는 컷이 좋습니다.
  신청폼 히어로는 세로로 긴 비율(16:14)로 잘리므로 가운데가 중요한 컷을 써주세요.
- **제품 사진** — 원본 비율 그대로 폭 100%로 표시됩니다. 가로로 긴 3종 컷이 가장 잘 어울립니다.

`.jpg` 로 올리실 경우 HTML 안의 `<img src="...">` 확장자도 함께 바꿔주세요.

## 3종 택 1

1인당 1개만 제공되므로 향을 고르는 지점이 두 군데 있습니다.

- **신청폼** — `flavor` 라디오 필드(필수). 선택값이 시트의 `제품 선택` 컬럼에 저장됩니다.
- **가이드라인(`guide.html`)** — 받으신 향을 누르면 해당 향의 핵심 역할 · 카피 · 권장 상황 · 맛 표현만
  펼쳐집니다. 선택값은 브라우저(localStorage)에만 남고 어디로도 전송되지 않습니다.

## 확정 후 채워야 하는 항목

- **공동작업자 인스타그램 계정** — `guide.html`, `*-type/index.html`
- **해시태그** — `guide.html` 의 `.hashtag-wrap` (현재 값은 브랜드명 기준 임시안)
- **레퍼런스 콘텐츠** — `guide.html` 에 레퍼런스 섹션 미포함 (링크 확보 후 추가)
- **`og:url` / `og:image`** — `guide.html` head, 배포 도메인 확정 후

## 신청폼 연동

각 타입 페이지의 `<form id="applyForm" ... action="...">` URL이 Apps Script 웹 앱 주소입니다.
현재는 기존 SIRIAI 캠페인과 동일한 엔드포인트를 사용하며 `campaign` 값(`리브러쉬 과즙 구강스프레이`)으로
시트에서 구분됩니다.

> ⚠️ **`제품 선택`(향) 컬럼은 스크립트를 다시 배포해야 저장됩니다.**
> 현재 배포된 스크립트는 12개 컬럼까지만 기록하므로, `apps-script.gs` 를 시트에 반영하고
> 재배포하기 전까지 `flavor` 값은 저장되지 않습니다.
